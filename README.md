# Excel Skills Lab

Static website featuring Excel flashcards and a mini quiz.

## Run locally
Open `index.html` in Chrome, or open the folder in VS Code and use Live Server.

## Deploy
### Netlify
Drag and drop this folder into Netlify's deploy interface.

### GitHub Pages
Push `index.html` to the root of a GitHub repository, then enable Pages under Settings > Pages, deploying from the main branch/root.

### Vercel
Import the repository as a static site. No build command or framework is required.

## Files
- `index.html`: complete standalone website.
